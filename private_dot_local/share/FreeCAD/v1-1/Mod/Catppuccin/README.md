# Catppuccin Theme and Preference Pack

This package contains dark and light themes matching the [Catppuccin](https://catppuccin.com) color palette.
Once installed, you can select and apply your preferred CatppuccinThemes (Lights or Nights) in the `Preferences > General` section.
